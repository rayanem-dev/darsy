# Coursup — habitudes du projet

- **Livraison :** après chaque série de modifications, pousser la branche de travail, créer la pull request vers `main` et la **fusionner directement** (autorisation permanente du propriétaire, pas besoin de redemander).
- **Nom :** l'application s'appelle **Darsy+** (ex-Coursup). Dépôts : `rayanem-dev/darsy` (public, GitHub Pages : https://rayanem-dev.github.io/darsy/) et `rayanem-dev/darsy-prive` (privé).
- **Comptes :** un seul site, une seule adresse. Écran de connexion / inscription ; l'admin arrive sur son tableau de bord (servi par le serveur, jamais présent dans ce dépôt public), les clients sur leur Darsy+. Jeton de session dans `localStorage` (`darsy_token`). Si le serveur est ancien (sans comptes), le site fonctionne comme avant (mode « legacy »). Aucune donnée, clé ni code d'administration ne doit être ajouté ici.
- **Charte (comme les autres sites) :** pied de page, langue et thème viennent de la brique `basdepage` de `rayanem-dev/lib` (copiée telle quelle : `basdepage.js`, `basdepage.css`, ne pas la modifier ici) ; aide intégrée (bouton « ? » et lien « Aide » du pied de page, guides par rôle avec captures dans `aide/`, regénérées par `tools/captures-aide.js` du dépôt privé) ; logo `logo.svg` + icônes PNG. `version.json` contient la même version que `APP_VERSION` (à mettre à jour à chaque livraison, sinon le pied de page affiche ⚠). **Langues : français, arabe (de droite à gauche) et anglais** via `i18n.js` : le code reste écrit en français, chaque texte affiché est traduit à l'apparition à partir du dictionnaire `D` (clé = texte français, `#` = nombre). **Tout nouveau texte visible doit être ajouté dans `D` (ar + en)** ; l'aide a ses propres traductions (`AIDE_L`) ; l'interface d'administration servie par le serveur reste en français. Captures de l'aide : `tools/captures-aide.js` du dépôt privé avec `L=fr|ar|en`. Menu du haut : Accueil · Séances · Sessions · Paiements · Calendrier (· Sujets pour le compte d'origine) ; Réglages = engrenage dans l'en-tête.
- **Thèmes de couleurs :** défaut indigo (`#3b5bdb` → `#7048e8`) ; le sélecteur 🎨 (en-tête et Réglages) tourne la teinte de tout le site (Indigo, Océan, Forêt, Rose, Ardoise). Les couleurs de la famille « bleu » sont des variables `--k-xxxxxx` (jamais de bleu en dur) ; le logo (livre argenté avec « درسي » sur fond nuit) est un SVG en ligne dont la tuile suit le thème (`logo.svg` + icônes PNG = version indigo). Les versions des images sont suffixées `?v=` (à mettre à jour avec la version).
- **Données personnelles :** jamais de vrai nom, e-mail ou photo d'enfant dans ce dépôt public (captures de l'aide avec des noms fictifs, aucune photo par défaut).
- **Connexion et famille :** case « Rester connecté sur cet appareil » (jeton durable 30 jours dans `localStorage`, sinon session courte dans `sessionStorage`), bouton 🚪 de déconnexion dans l'en-tête. Réglages → « Inviter ma famille » : jusqu'à 5 invités par e-mail (lien `?invitation=CODE` → l'invité choisit son mot de passe et partage le classeur du titulaire). Toute nouvelle action serveur de ce type doit être ajoutée aussi au dictionnaire `i18n.js`.
- **Langue :** répondre et écrire les commits en français.
- **Vérification avant fusion :** contrôler la syntaxe du JS de `index.html` (`node --check`) et tester le rendu avec des données simulées. Le `Code.gs` se vérifie dans le dépôt privé.
- **Semaine :** elle commence le **dimanche**.
- **Icônes :** liens directs `https://rayanem-dev.github.io/darsy/icon-*.png` (pas de base64 dans `Code.gs`).
- **`Code.gs` (PRIVÉ) :** il n'est plus dans ce dépôt public mais dans `rayanem-dev/darsy-prive` (avec l'administration `supreme/`). Ne jamais le remettre ici ni dans GitHub Pages. Copie du script Apps Script déployé ; le propriétaire le colle lui-même dans Apps Script, penser à le rappeler quand il change. Les changements serveur se font dans `coursup-prive`, les changements d'interface ici.
- **Version :** à chaque livraison, incrémenter `APP_VERSION` (`index.html`) et `VERSION` (`Code.gs`) avec la même valeur (`AAAA.MM.JJ.n`) ; elle s'affiche en bas de l'appli et signale si le serveur n'est pas à jour.
- **Vocabulaire :** une **session** = un paquet de N cours payé d'un coup (jamais « mois » ni « cycle » dans l'interface ni dans les réponses). Un cours isolé = une **séance**. « Ce mois » reste réservé aux statistiques du calendrier (ex. « Encaissé ce mois »).
- **Argent :** les paiements sont des **dépenses** (ce que la famille paye aux profs), jamais des « encaissements ». Dire « dépensé », « payé », « reste à payer ».
- **Tarif libre :** un cours peut être « à tarif libre » (gestes de remerciement ponctuels, sans prix fixe) : jamais d'impayé ni d'alerte de paiement ; rappel doux dans l'appli seulement (pas dans Google Agenda) ; un geste compte dans les dépenses ; « Pas cette fois » = paiement de 0 DA en mode « Aucun geste ».
- **Version minimale du serveur :** `MIN_SERVER` (`index.html`) = plus ancienne version de `Code.gs` supportée ; à relever dès qu'une nouveauté dépend du serveur. Sous cette version, l'appli affiche un bandeau « serveur pas à jour ».
